# 채팅 웹 푸시

상태(2026-11-04): 코드와 스키마는 Production에 있으나 **VAPID 키가 없어 꺼져 있다**(다크 런치).
키가 없는 배포에서는 설정 카드·접속 표시·대기열 쓰기·메시지당 추가 조회가 전혀 없다.

## 범위
새 **1:1 채팅 메시지**만. 감사 쪽지, 완료 안내, AI 매칭, 키워드 알림, 공지, 기관 채팅방은 푸시하지 않는다.
알림 내용은 `MJU Find / 새로운 채팅 메시지가 도착했어요.`와 방 주소뿐(메시지·게시글 제목·이름 없음). 클릭하면 그 채팅방.

## 구조
- 표준 Web Push + VAPID(`web-push`), 유료 푸시 서비스 없음. 서비스 워커 `public/sw.js`(캐시·오프라인 없음).
- 구독은 기기별(`PushSubscription`, 사용자당 최대 10기기). 엔드포인트는 브라우저 푸시 서비스 호스트
  (FCM·Mozilla·Apple·Windows)만 허용한다 — 임의 주소로 서버가 요청을 보내지 않도록.
- 메시지 저장 트랜잭션이 `PushOutbox` 한 행을 함께 쓰고(구독이 있을 때만), 응답 뒤 `after()`에서 발송한다.
  행당 한 번 선점(compare-and-set), 일시 실패는 3초 뒤 1회 재시도, 이후 새 채팅 활동이 15초 이상 지난 미발송 행을
  최대 3회까지 이어서 시도한다(15분 안). 발송 실패는 메시지 전송에 영향이 없다. 7일 지난 행은 일일 cron이 정리.
- 만료(404/410) 구독은 삭제. 오류 기록에는 엔드포인트를 남기지 않는다. 로그아웃은 그 기기의 구독만 삭제,
  비활성화·탈퇴는 계정의 모든 구독을 삭제한다.
- 중복 억제: 방을 보고 있는 탭(보이는 탭)이 10초마다 알리고 25초 안이면 그 방의 푸시를 건너뛴다.
  **한계:** 탭을 갑자기 닫으면 최대 약 25초 동안 한 건이 억제될 수 있다. 서버가 완전한 중복 제거를 보장할 수는 없다.
- 설정: 내 정보 > 채팅 푸시 알림. 기본 꺼짐, 켤 때만 권한 요청, 거부되면 다시 묻지 않고 허용 방법 안내.
  인앱 브라우저(카카오톡·에브리타임 등)와 아이폰 Safari 탭(홈 화면 웹 앱 + iOS 16.4+ 필요)은 요청하지 않고 안내한다.

## 켜는 방법 (Production)
먼저 확인할 것
1. **개인정보처리방침 개정**: 푸시 구독 정보(푸시 서비스 주소·암호화 키·기기명)와 브라우저 제조사 푸시 서비스로의
   전송이 수집 항목·위탁/제공에 없다. 개정·공지 절차(`lib/policy/privacyPolicy.ts`)와 법적 검토가 필요하다.
2. **실기기 확인**: 안드로이드 Chrome, 아이폰 홈 화면 웹 앱에서 구독→수신→클릭 이동→해제를 확인한다.
   (지금까지: 실제 Edge + Windows 푸시 서비스에서 구독·발송·서비스 워커 알림·해제를 확인, 휴대폰은 미확인.)

그 다음
```
node -e "const k=require('web-push').generateVAPIDKeys();console.log(JSON.stringify(k))"   # 출력은 공유하지 말 것
vercel env add VAPID_PUBLIC_KEY production        # 값 붙여넣기
vercel env add VAPID_PRIVATE_KEY production --sensitive
# (선택) VAPID_SUBJECT=mailto:연락처
vercel redeploy / deploy --prod
```
끄기: 두 변수를 지우고 다시 배포한다(남은 구독 행은 무해, 필요하면 `PushSubscription`을 비운다).
키를 바꾸면 기존 구독은 모두 무효가 된다(사용자가 다시 켜야 함).

## 검증 기록 (Preview DB, 로컬 `next start` 같은 커밋)
- 모의 푸시 서버(암호화된 요청을 복호화): 두 기기 각각 1건, 내용·VAPID 서명·TTL, 방을 보는 중 건너뜀, 떠난 뒤 발송,
  오래된 표시 무시, 503 실패 후 재시도(시도 횟수·중복 없음), 410 구독 삭제, 완료·쪽지는 푸시 없음, 구독 해제 후 큐 없음.
- 실제 Edge: 설정 카드에서 구독 → 서버 발송 → 서비스 워커가 알림 1건 표시 → 해제. 알림 클릭 이동은 자동화로 눌러 볼 수 없어 미검증.
